04Questions

Before you install.

Is Hollow Launcher free?

Yes. The launcher and its source code are free. No paid tiers, no ads.

Do I need to own Minecraft?

Yes. You sign in with the Microsoft account that owns Minecraft: Java Edition. Hollow does not offer cracked or offline-only play.

Which Minecraft versions are supported?

Everything from 1.8.9 through 26.3, installed side by side from a single launcher. New Minecraft releases are added as they ship.

Does it work on macOS and Linux?

Yes. There are builds for Windows, macOS and Linux.

Do I need Java installed?

No. The launcher downloads the Java version each Minecraft version needs and uses it only for Hollow, so nothing else on your machine is touched.

What happens to my worlds and other launchers?

They stay exactly where they are. Hollow keeps its own folder, so the official launcher and any other keep working. Uninstalling leaves your saves untouched.

Can mods get me banned?

The launcher itself does not change how you play, but some servers ban certain mods. Check each server's rules before you install anything.
