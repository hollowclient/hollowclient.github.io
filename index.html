04Questions

Before you install.

Is Hollow Client free?

Yes. The client, the mod library and the cosmetics are all free. No paid tiers, no ads inside the launcher.

Will using it get me banned?

Hollow only changes what happens on your screen. It never sends modified packets, so servers see a vanilla client — it is safe anywhere vanilla is allowed. Check each server's rules anyway.

Which Minecraft versions are supported?

Everything from 1.8.9 through 26.3, installed side by side from a single launcher. New Minecraft releases are added as they ship.

Does it work on macOS and Linux?

Yes. There are native builds for both, including Apple silicon. Performance tuning is identical to the Windows build.

Do I need Java installed?

No. A tuned Java 17 runtime ships inside the installer and is only used by Hollow, so it will not touch anything else on your machine.

What happens to my worlds and other mods?

They stay exactly where they are. Hollow keeps its own folder, so vanilla and any other client keep working the way they always did. Uninstalling leaves your saves untouched.
